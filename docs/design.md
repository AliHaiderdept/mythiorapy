# Meridian — Design Specification

## Direction
“Kinetic glass studio,” softened with calm sage and restrained motion. The interface combines editorial clarity with a precise personal journal. It should feel capable, private, and reassuring rather than clinical or playful.

## Visual system
- Display: Anton for concise uppercase statements and section labels.
- Body: Inter for accessible reading.
- Metadata: JetBrains Mono for dates, scores, and statuses.
- Palette: immersive teal wellness background with a soft central glow and darker edge falloff, deep ink text, translucent white surfaces, calm sage primary, restrained blue informational accents, and warm ochre premium cues.
- Atmosphere: a fine low-opacity grain layer adds the tactile poster quality of the visual reference without using the reference image itself.
- Shape: 8–16px radii for controls and cards; no exaggerated pill-heavy treatment.
- Surfaces: thin cool borders and light translucency, with no heavy shadows.

## Layout
- Sticky slim header with compact navigation.
- Twelve-column dashboard grid.
- Primary daily summary occupies two-thirds width on desktop.
- Stability index occupies one-third.
- Assessment and result details form the next row.
- Premium library uses four equal cards.
- Mobile collapses to a single column with an accessible menu.

## Interaction
- Main controls provide immediate visual state changes.
- Hover movement is limited to imagery and opacity.
- Entrance animation is short, subtle, and disabled by reduced-motion preferences.
- Keyboard focus must remain visible.

## Accessibility
- WCAG AA contrast target.
- Semantic headings and labeled navigation.
- Buttons use explicit labels; decorative imagery has empty alternative text.
- Status is communicated with both words and color.
- Content must remain usable at 200% zoom and at 320px width.

## Content tone
Calm, direct, non-judgmental, and specific. Avoid claims that the product diagnoses, treats, or guarantees outcomes.
